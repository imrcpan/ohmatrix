# Changelog

All notable changes to OhMatrix are written here, newest first. The text of a version is what its GitHub release says (the publish workflow
takes the section whose heading is `## [x.y.z]`; a version with no section gets the notes GitHub generates from the commits).
A version lists what changed since the version before it.

## [1.2.3] - 2026-11-14

- Better and smoother animation effects.

## [1.2.2] - 2026-11-13

- Fix abnormal display of transparent avatars.
- Optimized the style of voice message bubbles.

## [1.2.1] - 2026-11-11

Fix video preview on Android.

## [1.2.0] - 2026-11-06

OhMatrix is now available on Windows, Linux, macOS.

## [1.1.1] - 2026-11-04

Android: OhMatrix is a target of the system share sheet. Pictures, files and text shared from other apps open a page to choose the chats they are for.

## [1.1.0] - 2026-11-03

- Chat list now switches to a compact view when dragged narrow in landscape mode.
- Improved the layout of your profile and its settings in landscape mode.
- Links to a person now open their profile in the app instead of the web.
- Improved loading performance and interactions.
