# Open Emoji Cute

The emoji set that the sticker panel offers first, as it comes from <https://github.com/imrcpan/open-emoji-cute> (revision
`8457277a2fac1a3fdbc1d8d60f4cf24a45d19ad1`), licensed under the Apache License 2.0 (<https://www.apache.org/licenses/LICENSE-2.0>).

The SVG files here are unchanged. `src/chat/openEmoji.ts` holds them drawn as 256 px PNG pictures: `pnpm --filter @ohmatrix/app make-open-emoji`
makes it again from these files.
